# atelier

Welcome to Atelier, my Software Factory & AI Toolbox

Inspired by my teammate (RascalTwo) and other incredible developers in the AI space, I finally sat down to build a centralized home for my work. This repository is a curated collection of everything I’ve personalized, from daily development scripts to specialized AI tools.

## Layout

- `setup/notes/` — working notes
  - `glossary.md` — plain-language definitions of jargon as it comes up
  - `joseph-setup-plain.md` — RascalTwo's 16-stop setup tour, rewritten simply
  - `decisions.md` — what's decided, what's wanted, open questions, next steps
- `chats/` — transcripts of the Claude Code sessions that produced this work.
  `*.md` is the readable version. `*.raw.jsonl` is the full machine log and
  is gitignored.

## Picking up on another machine

1. Clone this repo.
2. Read `setup/notes/decisions.md` — it has the current state and open questions.
3. Open Claude Code in the repo root and point it at `chats/` for full context.
